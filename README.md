## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **CSV Import** | Load any FrameView CSV log file for instant analysis |
| **FPS Charts** | Visualize average, 1% low and 0.1% low FPS across the run |
| **Frame Time Graph** | Plot frame time over time to spot stutters and hitches |
| **Run Compare** | Load two runs side by side for direct benchmark comparison |
